# Robot descriptions v2.14.0

A clearer package layout for PAR6, PAROL6, MSG and SSG48 in both formats.

- `docs/` contains detailed model notes, comparison diagrams and dimensioned review sheets.
- `previews/` contains catalog/model PNGs; package metadata points to their new paths.
- Model and scene entry files remain at the root. Mesh/texture paths, joint definitions, masses, COM, inertia, collisions and actuator settings are unchanged.
- ROS installation and all generators preserve the new layout. Package checks validate local documentation and preview links after extraction.
- PAR6/PAROL6 getting-started guides have prominent images; loose repository feature PNGs are grouped in `docs/images/`.

Eight independent ZIPs are provided, plus the twelve-page kinematic review PDF, release manifest and SHA256SUMS. Existing releases remain available.
