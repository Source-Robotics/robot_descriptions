source and license, retain supplied notices, and indicate your changes.

This example can name only the products you actually use. The full license
terms govern use; the example is a convenient attribution format.

## Software and original records

The Python tools/tests, CI workflow, ROS launch/support scripts and CMake
build/install code remain under [Apache-2.0](LICENSES/Apache-2.0.txt).
Creative Commons recommends using a software license for code; see its
[software licensing FAQ](https://creativecommons.org/faq/#can-i-apply-a-creative-commons-license-to-software).
URDF model packages include that license under `docs/LICENSE-CODE.txt`.
External dependencies and separately linked hardware/firmware repositories
retain their own licenses.

The CC BY 4.0 model declaration begins with **v2.15.0**. Published releases
through v2.14.0 retain the Apache-2.0 grants under which they were distributed;
those archives and tags are not rewritten. Original exports under
`source/legacy/` and `source/parol6/original/` retain their historical metadata
as provenance records; it does not override the license of the newly generated
model packages. Existing license grants are not revoked.
