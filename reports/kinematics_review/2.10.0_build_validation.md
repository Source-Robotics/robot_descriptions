# Review-sheet build validation - 2.10.0

Validated locally on 2026-10-31 with the locked CPython 3.11 authoring environment.

- 46 description/reference/portability tests passed in the independent checkout.
- Full build from a fresh local Git clone passed, including CAD assets, both robot families, dynamics/jaw checks, ten review sheets and all four release archives. No external runtime/application imports or OpenGL render refresh were needed.
- Final review-generator changes were rerun in the clone; its 13 review tests passed. Regenerated model/review contents match the authoring checkout, and all four ZIPs match byte for byte. The archive-size report also matches the final packages.

- Three temporary foreground markers per snapshot independently verified overlay registration; maximum error 0.409 pixels. Every snapshot is orthographic and uses the same camera/scale.
- All ten final A4 PDF pages were rasterized and visually inspected. Page count, page dimensions and table text were checked. Both offline HTML selectors were exercised across all ten existing SVG targets.
- Thirty model definition files (ten URDFs, ten native models and ten scenes) match the previous 2.9.1 checkout, allowing only text line-ending normalization. They also retain their exact pre-build bytes in the authoring checkout. Geometry, collisions, kinematics, inertias and drive settings are unchanged; the added documentation is not loaded by the simulator.
- All five SVG/PNG/JSON sets in each native package match their URDF-package copies. Model provenance hashes use canonical LF and verify in both checkouts.
