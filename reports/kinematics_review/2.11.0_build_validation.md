# Review-sheet and wrist-geometry validation - 2.11.0

Validated locally on 2026-10-31 with the locked CPython 3.11 authoring environment.

- `python -I tools/build.py --models-only` passed: reference synchronization, jaws/contacts, all PAROL6 profiles, ten model-derived review sheets, four release archives and sixteen native grasp-scene compilations. The build used the refreshed source render cache without requiring OpenGL.
- All 48 description/reference/portability tests passed, including actual-mesh mounting-clearance checks in both URDF and native MuJoCo.
- Both robots use a5 = 177 mm. PAROL6 lower-arm visual/collision origins move -0.65 mm on wrist_1_link local Z; its J5 origin is -177 mm. Original mesh triangle records are unchanged.
- The largest connected wrist housings end at +41.1 mm (PAR6) and +34.5 mm (PAROL6) along wrist_2_link local Y. Protruding internal motor/shaft components are excluded from this mounting-face measurement.
- Matching PAR6 housing-to-flange rear-face clearance gives PAROL6 a6 = 50.5 mm, versus PAR6 57.1 mm. Mesh checks confirm approximately 1 mm clearance in both formats. All PAROL6 tools and TCPs move inward 6.6 mm relative to J6; gripper TCP axial reach is 134.3 mm versus PAR6 140.9 mm. This correction is CAD-derived, not an independent hardware measurement.
- All five profiles passed 160-pose source/arm-frame/tool/dynamics checks. J1-J6 frames match PAR6 (residual below 1e-8 mm). An independent vector check verifies the exact -6.6 mm flange shift along J6 local Z. Each tool-specific DH table additionally passed 128-pose URDF/native comparisons.
- Every explicit inertial in both PAROL6 formats matches 2.10.0. Every massive compiled body's local mass/COM/inertia, armature, damping/friction and actuator settings is unchanged. MuJoCo's derived COM bookkeeping for the massless flange frame shifts with its children; it is not a physical inertia change. Generalized dynamics change with the corrected geometry/tool leverage as expected.
- All PAR6 model/geometry assets match the 2.10.0 baseline; package-version metadata and comparison/review documents were updated. PAROL6's preserved original source files pass their provenance hashes.
- All ten final A4 PDF pages were rasterized and visually inspected; dimensions, page count and table text were checked. The offline comparison, all SVG/PNG/JSON sheets and PAROL6 preview gallery were refreshed. URDF/native review copies and source hashes agree.
- The previous 2.10.0 build report and model-definition hashes are archived beside this report. Current model-definition hashes are in `model_definition_baseline.json`.
