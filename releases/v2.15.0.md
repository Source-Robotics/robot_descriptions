# Robot descriptions v2.15.0

## Model licensing

PAR6, PAROL6, MSG and SSG48 model descriptions, meshes, physical data, textures, previews and documentation are now CC BY 4.0. Each of the eight downloads carries the full license and a Source Robotics attribution example. Python/ROS support code remains Apache-2.0, with a separate notice in URDF packages. Earlier published releases retain their original licenses and are not rewritten.

## Appearance documentation

The new `docs/COLORS.md` guide covers named motor/lens/jaw materials, HEX palettes, RGBA examples and regeneration. It explicitly describes which settings are centralized and which still require model/generator edits. All product guides link to it.

The PAROL6 six-configuration gallery now contains only the robot renders and end-effector labels; its dimension/estimate footer is removed. Model geometry, kinematics, physical properties and controls are unchanged.

Eight independent model ZIPs, the dimensioned review PDF, release manifest and checksums are provided.
